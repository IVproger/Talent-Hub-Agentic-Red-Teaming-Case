# Сравнительный анализ конкурентов: Agentic Red Teaming (компрометация памяти и инструментов ИИ-агентов)

**Дата:** 2 сентября 2026
**Объект сравнения:** инструменты и услуги, которые закрывают хотя бы часть цепочки
`доставка атаки → контекст → persistent memory → планирование → выбор/аргументы инструмента → выполнение → изменение состояния → cross-session → трассировка / ASR`

**Охват версии:** из 14 российских и 25+ зарубежных игроков, исследованных в исходных отчётах, в этот документ включены **топ-5 по каждому рынку**. Игроки ниже 5-й позиции удалены целиком (профили, строки таблиц, столбцы capability-матрицы, ценовые якоря).

**Скоуп — только red teaming (offensive).** Из профилей оставшихся игроков убраны defensive-компоненты: runtime-файрволы, guardrails, AI-шлюзы, posture/SPM-модули, governance- и комплаенс-тиры. Они не конкурируют с кейсом по функции и в сравнении не участвуют. Там, где defensive-часть влияет на оценку конкурента (пивот, канал продаж, происхождение фичи), это отмечено отдельной строкой «Вне скоупа».

## 1. Критерии сравнения

**Уровни близости к кейсу:**

| Уровень | Что закрывает |
|---|---|
| **A — прямой** | Автоматизированный agentic red teaming: tool chains, MCP, multi-agent, state |
| **B — частичный** | LLM red teaming с поддержкой приложений/RAG/агентов, но модель-центричный |
| **D — сервис** | Пентест, аудит ИИ, Red Team как услуга (human-led) |

Уровень «C — смежный» (guardrails / AI firewall / runtime) в этой версии не используется: такие решения не являются red teaming и из сравнения исключены.

**Что означает «время проведения аудита»:** для платформ — время одного прогона + onboarding; для сервисов — срок engagement. Там, где вендор не публикует, указан отраслевой ориентир с пометкой «~».

**Легенда capability:** ● заявлено и детализировано · ◐ заявлено без деталей · ○ нет · ? нет данных

**Критерии ранжирования — Россия:** (1) доступность для банка (on-prem, реестр, санкции), (2) глубина покрытия агентной цепочки (память, tool-args, cross-session), (3) RU-регуляторика, (4) прозрачность цены, (5) стратегический риск для новой команды.

**Критерии ранжирования — зарубеж:** (1) близость к цепочке кейса (память, tool-args, cross-session, трасса), (2) зрелость и доказательная база, (3) прозрачность методики и цены, (4) возможность изолированного развёртывания.

## 2. Российский рынок — топ-5

### 2.1. Контекст и ограничения, критичные для банка [^1] [^2]

1. **Зарубежные SaaS-платформы (Pillar, Straiker, SPLX SaaS, Microsoft Foundry) для российского банка практически недоступны** — санкционные ограничения на оплату и поддержку, отсутствие в реестре отечественного ПО, невозможность передачи данных банка во внешний контур. Реально доступны только on-prem/self-hosted варианты и open source [^2].
2. **LLM в контуре:** приказ ФСТЭК №117 (с 01.03.2026) запрещает передавать разработчикам ИИ информацию ограниченного доступа; 152-ФЗ требует локализации ПДн; Методические рекомендации Банка России от 16.06.2026 фиксируют требования к ИБ ИИ на финрынке. Следствие: и атакующая LLM, и LLM-судья, и целевой агент должны работать на локальных/отечественных моделях (GigaChat, YandexGPT, T-Pro, open-weights Qwen/Llama on-prem). Зарубежные облачные API (OpenAI, Anthropic, Google) в банковском контуре не применимы [^1].
3. **Регуляторный драйвер спроса:** Минцифры включило обязательный анализ защищённости ИИ-моделей в типовое ТЗ к Указу №250; для банков действует 851-П (ежегодный пентест), для НФО — 757-П. 243-ФЗ «О поддержке развития технологий ИИ» (с 01.09.2026) обязанностей по проверке защищённости **не вводит** [^3].
4. **Маппинг на БДУ ФСТЭК, приказ №117 и рекомендации ЦБ** есть только у российских игроков (HiveTrace, Кредо-С); ни один западный вендор его не предоставляет.
5. **Цены в РФ:** разброс при одинаковом ТЗ достигает 2–4 раз; премия за финтех/банки +30–100%; отчёт для регулятора/ФСТЭК +100–300 тыс. ₽; срочность <2 недель +30–50% [^5].

### 2.2. Профили игроков

#### 1. HiveTrace / HiveTrace Red — главный локальный конкурент (уровень B)
- **Сайт:** https://hivetrace.ru/red · спин-офф Raft Digital Solutions + AI Security Lab ИТМО/МФТИ (2025). Референс из ТЗ кейса.
- **Продукт (в скоупе):** HiveTrace Red — offensive-сканер LLM-моделей и GenAI-систем.
- **Техника:** 91 атака в 12 категориях, 80+ типов расширения тестового набора; **нативная поддержка GigaChat и YandexGPT**; API + локальные модели; HTML-отчёт с маппингом **ФСТЭК-117 / OWASP LLM Top 10 / MITRE ATLAS**. OSS-часть — Apache 2.0 (09.2025), Enterprise — 05.2026 + партнёрская программа для интеграторов.
- **Кейсы:** один из четырёх вендоров финального опроса TAdviser по рынку AI Security РФ; используется Кредо-С как партнёрское решение для непрерывного red teaming.
- **Стоимость:** не публикуется.
- **Плюсы:** единственный российский offensive-продукт (не услуга); отечественные LLM «из коробки»; RU-маппинг; OSS-ядро.
- **Вне скоупа:** HiveTrace Monitoring (runtime-контроль вызовов инструментов) — defensive, в сравнении не учитывается, но показывает, что вендор уже видит tool calls и может перенести это в offensive-часть.
- **Минусы:** объект — «LLM-модели и GenAI-системы», т.е. модель и диалог; публично нет атак на долговременную память, cross-session проверок, memory diff, cross-user contamination, оракулов по tool-args.

#### 2. Positive Technologies (уровень D)
- **Контакт:** secserv@ptsecurity.com · блог https://habr.com/ru/companies/pt/articles/971062/
- **Продукт:** аудит LLM-агентов как услуга; внутренняя команда offensive AI security с собственным исследовательским фреймворком; PT Dephaze (авто-пентест инфраструктуры, не LLM); Standoff 365 (27 000+ исследователей).
- **Экспертиза:** публичный разбор Agent Breaker CTF; исследования prompt injection, data poisoning, fingerprinting LLM (96,5% точность).
- **Стоимость:** индивидуально; цены защитных продуктов вендора **не относятся** к AI red teaming.
- **Вне скоупа:** PT Naira, PT Data Security, PT AF и прочие defensive-продукты.
- **Плюсы:** сильнейшая в РФ offensive-экспертиза по агентам; лидер рынка (>60% рынка пентеста у тройки PT / BI.ZONE / Solar).
- **Минусы:** коммерческого agentic-продукта нет; **риск быстрого выпуска продукта** — главная стратегическая угроза для новой команды.

#### 3. Кредо-С — единственный публичный прайс (уровень D)
- **Сайт:** https://www.credos.ru/uslugi/informatsionnaya-bezopasnost/audit-bezopasnosti-ii-sistem/
- **Продукт (услуга):** аудит защищённости LLM-приложения (**от 400 тыс. ₽**) → оценка защищённости ИИ-системы с моделированием угроз, **ИИ-агентами и интеграциями** (**от 600 тыс. ₽**) → LLMSecOps (**от 800 тыс. ₽**). Срок 2–6 недель. Лицензия ФСТЭК на ТЗКИ.
- **Вне скоупа:** тир «оценка рисков ИИ и фреймворк управления, ФСТЭК/152-ФЗ» (от 1 млн ₽) — governance, не red teaming.
- **Методологии:** OWASP LLM Top-10, MITRE ATLAS, NIST AI RMF, DASF, **БДУ ФСТЭК**; проверяют **ИИ-агентов, их доступы и function calling**.
- **Кейсы (под NDA):** prompt injection + утечка через RAG в обход прав; **ИИ-агент с избыточными доступами, выполняющий действия за пределами роли**; передача ПДн в облачную LLM в финсекторе.
- **Плюсы:** прозрачная цена; агенты и function calling в скоупе; RU-регуляторика; retest включён.
- **Минусы:** консалтинг, не продукт — нет автогенерации многошаговых атак, нет ASR; непрерывный red teaming через партнёра HiveTrace; persistent memory между сессиями не заявлена; цены «от», для банков/КИИ вырастут.

#### 4. BI.ZONE (уровень D)
- **Сайт:** https://bi.zone/catalog/services/red-team/
- **Продукт:** BI.ZONE Red Team — 7-этапный классический red teaming (сценарии → сбор данных → первичный доступ → развитие атаки до бизнес-риска → фиксация → разбор с blue team → контрольная проверка).
- **Данные:** за июль 2025–июль 2026 проникновение во внутренний периметр в 93% проектов, полное достижение целей — 85%, 820+ уязвимостей; **признаки использования ИИ-агентов найдены у 72% организаций**.
- **Стоимость:** индивидуально, проектная форма (крупный бизнес — 64% проектов). Ориентир рынка: Red Team без TI от 1,5 млн ₽, с TI от 3 млн ₽, enterprise 2–3 мес — 5–50+ млн ₽ [^5].
- **Плюсы:** зрелый процесс, банковская клиентура, статистика.
- **Минусы:** ИИ-агенты — часть общего red teaming, не отдельный продукт; AI/memory-методики не раскрыты; низкая повторяемость между релизами; клиент получает отчёт, а не инструмент.

#### 5. Сбер / СберТех — AI RedTeaming (in-house, уровень A по замыслу)
- **Источник:** доклады DevOpsConf, OFFZONE 2026.
- **Что заявлено (в скоупе):** внутреннее направление AI RedTeaming; **обязательная статическая и динамическая проверка инструментов и анализ опасных комбинаций инструментов** в корпоративном реестре навыков — фактически offensive-анализ tool-графа перед допуском агента в прод.
- **Вне скоупа:** AI Security Gateway, AI Guardrails, изоляция контуров, песочница для кода — защитный периметр.
- **Стоимость:** внутренний продукт, не продаётся.
- **Плюсы/риск:** технически самое близкое к кейсу в РФ («анализ опасных комбинаций инструментов» = toxic-flow-граф). Публичного offensive-продукта нет → ниша открыта, но именно Сбер может её закрыть первым.

## 3. Зарубежный рынок — топ-5

### 3.1. Профили игроков

#### 1. Pillar Security (Израиль/США) — ближайший конкурент (уровень A)
- **Сайт:** https://www.pillar.security/ · seed $9M (04.2025, Shield Capital) · упоминается признание Gartner.
- **Продукт (в скоупе):** **RedGraph / Red Graph Suite** (12.2025 / 08.2026) — автоматизированный agentic red teaming; опирается на инвентаризацию агентов, моделей и MCP.
- **Вне скоупа:** runtime AI-firewall с taint-анализом, AI-SPM как postura-продукт.
- **Техника:** поверхность атаки как **граф** «агенты — инструменты — права — источники данных»; находит эксплуатируемые цепочки, где безопасные по отдельности компоненты дают составной риск; multi-step black-box атаки **через реальный интерфейс приложения** (браузер); «proof of what was executed»; версионирование постуры между релизами; отдельная фича **red teaming for tool use**. Вход — URL + креды. Совместимость: Microsoft Copilot, Salesforce Agentforce, Google Agentspace, n8n.
- **Стоимость:** **$175 000 / 12 мес** (AWS Marketplace, list price, 0 отзывов) [^4].
- **Плюсы:** маркетинг дословно совпадает с тезисом кейса («model-only testing misses the tool chains…»); граф атак; multi-turn tool hijacking + lateral movement.
- **Минусы:** дорого; закрытый SaaS, требует live-окружения (не изолированный тестовый контур); память — элемент графа, а не измеряемый цикл write→persist→retrieve→act; нет cross-session/cross-user метрик; нет RU-маппинга; покупательская база не подтверждена.

#### 2. Straiker (США) — ближайший функциональный аналог (уровень A/B)
- **Сайт:** https://www.straiker.ai/ · инвесторы Lightspeed, Bain Capital Ventures.
- **Продукт (в скоупе):** **Discover Agent** (карта поведения: инструменты, источники, инфраструктура) + **Ascend AI / Attack Agent** (адаптивные кампании на unaligned/fine-tuned/frontier моделях). CI/CD, OWASP/ATLAS/EU AI Act.
- **Вне скоупа:** Defend AI (runtime), куда автоматически уезжают найденные атаки в виде гардрейлов.
- **Техника:** цели в **бизнес-терминах** («перевести средства без одобрения», «эксфильтрировать поля из приватного индекса»); форензика **Chain of Threats** (какая категория, за сколько ходов, какие стратегии/модели/инструменты); дашборд с ASR, risk score, threat matrix; заявлено 98,1% threat detection. SLA: critical 2ч/1ч.
- **Кейсы:** Emergent (Wingman), отзыв Omada Health; контракты на 6–7-значные суммы в financial services, healthcare.
- **Стоимость:** **$100 000 / 12 мес** (AWS Marketplace, 0 отзывов) [^4].
- **Плюсы:** постановка целей = банковский кейс; ASR прямо в продукте; форензика многошаговой атаки.
- **Минусы:** архитектура раскрывается «на высоком уровне by design» — методика невоспроизводима; SaaS без изоляции; persistent memory в 5-слойной модели отсутствует как отдельная поверхность (см. п. 0.4); 98,1% — про detection, не про ASR многошаговых атак.

## 6. Выводы для позиционирования

1. **Прямого конкурента нет.** Ни один из десяти лидеров не автоматизирует полный цикл «threat model → multi-step сценарий → атака на persistent memory реального агента → трассировка → разложенный ASR» и не публикует воспроизводимую методику. Persistent memory упоминается в маркетинге у Pillar, Straiker, Repello и Adversa — без методики измерения.
2. **Cross-session delayed trigger и cross-user contamination не заявлены ни у кого** — это ядро кейса и главная точка дифференциации.
3. **Ближайшие по духу:** Pillar (граф атак, tool hijacking) и Straiker (бизнес-цели, Chain of Threats). Оба — закрытый SaaS, недоступный банку в РФ [^2].
4. **В РФ ниша свободна:** HiveTrace Red — модель-центричен; Кредо-С, PT, BI.ZONE — услуга без продукта и без ASR; Сбер — in-house, не продаётся.
5. **Уникальные преимущества локального продукта:** on-prem без передачи данных во внешний SaaS; локальные LLM (GigaChat/YandexGPT/open-weights) [^1]; маппинг на БДУ ФСТЭК / приказ №117 / рекомендации ЦБ от 16.06.2026 — чего западные вендоры не покрывают в принципе.
6. **Что заимствовать у лидеров (только offensive-практики):** Chain of Threats (Straiker) — для форензики; граф «агенты–инструменты–права–данные» (Pillar) — для моделирования поверхности; attack path «entry→escalation→impact» (Repello) — для отчёта; ASR как KPI — для методологической совместимости с мейнстримом.
7. **Гипотеза цены (аналитическая, не найденная):** пилот на одном агенте 300–500 тыс. ₽; разовая agentic security assessment 700 тыс. – 1,5 млн ₽; банковский workflow 1,5–3 млн ₽; team-лицензия 2–5 млн ₽/год; enterprise on-prem 5–10+ млн ₽/год. Логика: дешевле ручного Red Team (1,5–12 млн ₽), значительно дешевле западных платформ ($100–175k), повторяемее проекта.
