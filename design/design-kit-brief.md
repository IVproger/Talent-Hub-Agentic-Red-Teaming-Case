## Пять выводов, которые меняют дизайн

### 1. Альфа-Банк не красный

Расхожее представление неверно. По замерам живых страниц фирменный красный
занимает считанные проценты площади: логотип, одна кнопка на экран.
Доминируют почти чёрный `#121213`, белый и светло-серый `#f2f3f5`.

**Решение:** не красить интерфейс в красный. Экономия акцента — это и есть
следование бренду, а не отступление от него.

### 2. Тёмная тема у бренда своя

Раздел `alfabank.ru/corporate` свёрстан полностью в тёмной теме, и его
замеренные значения совпадают с токенами `--color-dark-*` один в один.

**Решение:** делаем инструмент в тёмной теме по умолчанию. Это уместно
для инструмента безопасности и при этом остаётся в рамках бренда.
Светлую тему поддерживаем — токены для неё уже есть, работы почти нет.

### 3. Два красных нельзя смешивать

| Роль | Токен | Значение |
| --- | --- | --- |
| Бренд, главное действие | `--color-light-accent-primary` | `#ef3124` |
| Критичная находка | `--color-light-status-negative` | `#ff4837` |

**Решение:** в нашем интерфейсе красный означает риск. Брендовый красный
остаётся только на знаке в шапке. Главную кнопку экрана красим брендовым
красным лишь там, где рядом нет индикаторов критичности.

### 4. Поверхности строятся прозрачностью

Карточка на тёмном фоне у Альфы — это `rgba(214, 214, 229, 0.07)`,
а не сплошной `#1c1c1e`.

**Решение:** берём этот приём целиком. В дашборде, где карточки лежат
на приглушённых заливках статусов, прозрачная поверхность сохраняет
единую логику вложенности, а сплошная — ломает её.

### 5. Радиусы бренда великоваты для нашего жанра

32 пикселя доминируют на витрине. В таблице находок со строками
высотой 44 пикселя такое скругление превращает строку в капсулу.

**Решение:** 32px оставляем крупным панелям, внутри переходим на 12–16px,
99px сохраняем для кнопок и тегов. Пластика узнаётся, плотность не страдает.

## Открытые вопросы: нужен ответ заказчика

Это блокеры не для работы, а для финальной сдачи. Работать можно уже сейчас.

1. **Шрифт.** Фирменный Styrene A под платной лицензией, интерфейсный
   Alfa Interface Sans публично не распространяется. Живой сайт использует
   системный стек. Нужно либо получить лицензию, либо согласовать замену.
   До ответа работаем на системном стеке, для макетов взят Golos Text.
2. **Официальный брендбук российского юрлица.** Скачанные файлы логотипов
   взяты с сайта белорусского банка группы. Цвет и знак совпадают, но для
   сдачи нужен комплект от заказчика.
3. **Доступ к внутренним интерфейсам.** Публичные сайты — это витрина.
   Интернет-банк и внутренние панели за авторизацией ближе к нашему жанру.
   Демо-стенд или внутренний Storybook был бы самым ценным референсом.
4. **Собственное имя и знак продукта.** Инструмент может иметь свою
   айдентику, а логотип банка выступать отметкой принадлежности. Это
   развязывает руки и снимает конфликт двух красных.

## Что проектируем сами

Публичные сайты банка не содержат компонентов, без которых инструмент
не работает. Их придётся спроектировать, опираясь на жанр панелей
наблюдаемости, но в палитре и типографике Альфы:

* таблица находок с сортировкой, фильтрами и приоритизацией;
* граф цепочки атаки: вход → контекст → память → планирование → выбор
  инструмента → аргументы → результат → изменение состояния;
* просмотрщик трассировки LangFuse со свёрнутыми шагами агента;
* diff состояния памяти агента до и после атаки;
* матрица покрытия по MITRE ATLAS;
* динамика Attack Success Rate во времени;
* сопоставительная таблица «риск / бенефит» для переговоров с командой агента.

Базовый слой закрывают готовые компоненты Core Components: там 132 пакета,
включая `table`, `chart`, `status-badge`, `segmented-control`, `tabs`,
`side-panel`, `steps`, `notification`, `tooltip`.

## Правила кодирования критичности

Цвет не должен быть единственным носителем смысла. Кодируем состояние
формой и цветом одновременно:

| Уровень | Цвет | Дополнительный признак |
| --- | --- | --- |
| Критично | `status-negative` | полоса слева 3px + бейдж заглавными |
| Высокий | `status-attention` | полоса слева + бейдж |
| Средний | `status-info` | бейдж без полосы |
| Отражено | `status-positive` | бейдж без полосы |

Пример реализации — раздел «Применение» в листе образцов
`05-ui-patterns/alfa-swatches.html`.

## Как переиспользовать собранное

```bash
# обновить токены из репозитория дизайн-системы
python3 design/parse_tokens.py

# пересобрать документацию по палитре и типографике
python3 design/build_docs.py

# пересобрать визуальный лист образцов
python3 design/build_swatches.py

# переснять сайты (все или одну цель)
python3 design/capture_sites.py
python3 design/capture_sites.py alfabank-ru-corporate
```

Подключение токенов в прототипе:

```html
<link rel="stylesheet" href="design/03-design-tokens/alfa-tokens.css">
```

Для Figma или Style Dictionary берите `03-design-tokens/tokens.w3c.json`
в формате W3C Design Tokens.
