# Продуктовые материалы

Комплект на финальную сдачу (07.09.2026) — три файла, каждый закрывает свою
часть требований:

1. [`01-product-brief-final.md`](01-product-brief-final.md) — **кто пользователь
   и какая проблема; уточнённая гипотеза и ценностное предложение; выбор
   сегмента; экономика; принятые решения и вклад AI Product; выводы.**
2. [`02-mvp-and-user-flow-final.md`](02-mvp-and-user-flow-final.md) — **границы
   реализованного MVP; основной пользовательский сценарий с реальными командами;
   таблица «продуктовое решение → техническое следствие → где в коде»; статус
   критерия завершения MVP.**
3. [`03-validation-results-and-risks-final.md`](03-validation-results-and-risks-final.md)
   — **критерии успеха, способ и результаты проверки; статус гипотез; риски и
   ограничения AI-решения; решения по ходу хакатона; выводы; пилот.**

Поддерживающие материалы (ссылки из трёх файлов выше):

- [`value.md`](value.md) — модель ценности: каждое число с источником, три
  сценария чувствительности, ответы на вопросы жюри по слайду.
- [`06-user-stories-and-backlog.md`](06-user-stories-and-backlog.md) — 36
  пользовательских историй и эпики E1–E9; по ним писались спеки и планы в
  `docs/blueprint/`.
- [`05-morok-brand-positioning.md`](05-morok-brand-positioning.md) — имя MOROK,
  позиционирование, мессенджинг, AS-IS / TO-BE. Датирован 04.09; цифры
  инженерной базы там исторические.
- [`07-concept-ui-description.md`](07-concept-ui-description.md) — концепция
  интерфейса, по которой собирались дизайн-кит и webui.
- [`context-pack-day1.md`](context-pack-day1.md) — исследовательский ground
  truth: сегменты, рынки, интервью, гипотезы.

История решений (не для сдачи): [`04-brand-positioning-and-naming.md`](04-brand-positioning-and-naming.md)
— лонг-лист названий; [`user-story-draft.md`](user-story-draft.md) — черновик
из 10 исходных сценариев.

Описание проекта целиком — [`../project-final-description.md`](../project-final-description.md);
