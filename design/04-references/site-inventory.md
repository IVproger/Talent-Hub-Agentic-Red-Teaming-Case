и JSON с замерами реальных стилей. Успешно снято 26 из 26 целей.

## Как читать снятое

```text
04-references/
├── screenshots/       26 JPEG: <slug>--desktop.jpg и <slug>--mobile.jpg
├── html-snapshots/    13 HTML: полный DOM после выполнения скриптов
├── extracted/         13 JSON: замеры + _capture-log.json со сводкой
├── brandbook-text/     2 TXT: извлечённый текст брендбуков
└── brandbook-pages/  107 JPEG: постранично отрисованные брендбуки
```

Скриншоты сняты полностраничными и пересохранены в JPEG качества 90;
мобильные приведены с 2x к 1x. В исходном PNG папка весила 77 МБ,
после сжатия 26 МБ при визуально неотличимом результате. Точные цвета
берите не из картинок, а из `extracted/*.json` и токенов —
там значения без потерь.

Сводный лог `extracted/_capture-log.json` содержит поле `screenshot`
с путём к файлу; в нём указаны имена на момент съёмки.

В каждом JSON из `extracted/`:

| Поле | Что содержит |
| --- | --- |
| `rootVars` | CSS-переменные, объявленные в `:root` |
| `fonts` | реально применённые гарнитуры с частотой |
| `fontSizes` | связки размер / насыщенность / интерлиньяж с частотой |
| `textColors`, `bgColors` | фактические цвета с частотой |
| `radii`, `shadows` | радиусы и тени с частотой |
| `h1`, `nav`, `title` | текстовая структура страницы |

Частота важнее списка: она показывает, что в системе норма, а что исключение.

## Ресурсы, которые сознательно не снимались

| Ресурс | Почему |
| --- | --- |
| `online.alfabank.ru`, Альфа-Онлайн | требует авторизации; снимать чужой личный кабинет нельзя |
| Альфа-Бизнес Онлайн, Альфа-Клиент Онлайн | то же, закрытый контур |
| Мобильные приложения | не веб; при необходимости берите скриншоты из сторов |
| `alfaforex`, Alfa Only | нишевые витрины, пластика повторяет основную |

Интерфейсы за авторизацией были бы ближе всего к нашему инструменту по жанру.
Если заказчик даст доступ к демо-стенду интернет-банка или к внутреннему
Storybook, это будет самый ценный референс из возможных. Стоит запросить.

## Технические заметки по захвату

* `alfabank.ru` защищён JS-челленджем ServicePipe. `curl` получает страницу-заглушку
  на 1770 байт, полноценный браузер челлендж проходит. Отсюда выбор Playwright.
* Российские домены отдают сертификаты, которым macOS не доверяет по умолчанию.
  В скрипте включён `ignore_https_errors`. Это допустимо для сбора публичных
  референсов и недопустимо для чего-либо ещё.
* Скрипт прокручивает страницу до конца перед съёмкой, иначе ленивые блоки
  остаются пустыми.
* Повторный запуск: `python3 design/capture_sites.py`, либо
  `python3 design/capture_sites.py alfabank-ru-main` для одной цели.
