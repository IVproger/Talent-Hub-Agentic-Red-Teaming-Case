> Кто за что отвечает и как раздать работу так, чтобы разные люди (каждый со
> своим агентом) реализовывали **независимо**, не наступая друг на друга.
> Опирается на [`morok-core-plan`](2026-09-05-morok-core-plan.md) (задачи 0.0–6.4).
>
> Дата: 2026-09-05 · Команда: Zero Trace

## 2. Стратегия: заморозить → распараллелить → собрать

Ключ к независимости — **сначала заморозить интерфейсы**, потом каждый пишет свой поток против них, файлы не пересекаются.

```
Фаза 0 (один владелец): заморозка интерфейсов + фейки
        │
Фаза 1 (параллельно, 4 потока): S1 core-logic · S2 profile · S3 adapter · S4 evidence
        │
Фаза 2 (один владелец): S5 runner (нужны S1–S4)
        │
Фаза 3 (параллельно): S6 CLI+UI · S7 carry-over+отчёт
```

## 8. Правила независимости (чтобы агенты не столкнулись)

1. **Один поток — свой каталог.** Пересечение файлов только в Фазе 0 (заморожена) и в `tests/fakes.py` (создан в 0.0, дальше read-only).
2. **Строишь против интерфейсов Фазы 0, не против чужого кода.** Нужен чужой модуль в тесте → бери фейк, не реальную реализацию.
3. **Зелёные тесты на границе каждой задачи.** `python -m unittest discover -s tests` перед коммитом.
4. **Grep-страж (0.7)** держит `normalize/assertions/campaign` target-независимыми — не тащи туда `cus`/`mongo`.
5. **Менять замороженный интерфейс** можно только согласованно (ломает всех): Даниил обновляет Фазу 0, уведомляет потоки.
6. **Свой мелкий коммит на задачу** (формат из плана), в своей ветке/worktree.

## 9. Как агент берёт поток

Промпт агенту: «Ты реализуешь поток **S<N>** из `docs/blueprint/plans/task-assignment.md`. Читай спек `2026-09-04-morok-core-design.md` и задачи <список> из `morok-core-plan.md`. Работай строго в каталоге <свой>, строй против интерфейсов Фазы 0, каждую задачу веди по TDD-шагам плана, на границе задачи — зелёный `unittest`, мелкий коммит. Не трогай чужие каталоги и замороженные интерфейсы.»

## 10. Критический путь

```
Фаза 0 (Даниил) → [S1,S2,S3,S4 параллельно] → S5 runner (Даниил) → [S6,S7 параллельно]
```

Узкие места — Фаза 0 (блокирует всех, делать первой и быстро) и S5 runner (сходятся все потоки). Остальное параллелится.
