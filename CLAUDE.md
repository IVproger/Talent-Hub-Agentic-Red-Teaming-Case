# MOROK — контекст для агентов

Движок **agentic red teaming**: по профилю цели запускает многошаговые атаки на
память и инструменты и доказывает эффект **наблюдаемым состоянием**, а не текстом
ответа модели. Дизайн: `docs/blueprint/` (спеки, планы, диаграммы). Текущий
прогресс и точки синхронизации: `docs/blueprint/plans/STATUS.md`.

## Архитектура (одной картинкой)

Три слоя, зависимость в одну сторону:
- **Граница цели** (плагины): адаптер (`adapters/`), личности, evidence-провайдеры (`evidence/`) — конфигурируются профилем.
- **Ядро** (`normalize/` → `assertions/` → `campaign/`): нормализация фактов → предикаты → вердикт → runner. **О цели не знает.**
- **Профиль** (`profile/`, `profiles/<name>/<version>.yaml`): единственный носитель target-специфики.

Диаграммы: `docs/blueprint/diagrams/` (0-overview* — верхнеуровнево).

## Инварианты (не нарушать)

- **Вердикт только из состояния.** Предикат на тексте ответа → градация `TEXT`, потолок `indirect`. (US-23)
- **Профиль — единственное место target-специфики.** Утечка `cus`/`mongo`/`invest-server`/`8600`/`agent_policy_memories` в `normalize/`/`assertions/`/`campaign/` = дефект. Ловит `tests/test_no_target_leak.py`.
- **Вызовы инструментов — первичный источник; память — усилитель.** Нет источника вызовов → `indirect`/`UNOBSERVABLE`, никогда «успех». (US-04 AC2)
- **`runs/<id>/` иммутабелен.** Регрессия/реплей создают новые каталоги.
- **Ошибочные попытки вне знаменателя ASR** (`error`, не в ASR).
- **Telemetry fail-open**: наблюдаемость прогона не влияет на вердикт; evidence-источник, наоборот, load-bearing (отказ → `error`).
- **Секретов в YAML нет** — только имена env.

## Как работать

- **Тесты:** `python -m unittest discover -s tests` (используй `.venv/bin/python`). На границе каждой задачи набор зелёный — все 441. Если `stand.observability` падает, venv отстал от `requirements.txt`: `.venv/bin/pip install -r requirements.txt` (нужен langfuse 4.x, он тянет opentelemetry).
- **TDD:** падающий тест → fail → минимальная реализация → pass → мелкий коммит (формат: `feat(scope): …`, wrap 72). **Без** `Claude-Session`-трейлера.
- **Big-bang миграция:** старый код (`client.py`, `tracer.py`, `state.py`, `scorers.py`, `target_runtime.py`, `pipeline.py`) переписывается на месте и удаляется, только когда новый путь (runner+CLI) заменит его целиком.
- **Язык:** доки/интерфейс — русский; код/идентификаторы — английский.
- **Разделение работы в реализации Ядра:** `docs/blueprint/plans/work-split.md` (dseredkin ↔ oushtt); правила независимости — `task-assignment.md`. Оба документа описывают только эту фазу, а не роли команды в целом. Свой поток — свой каталог, строй против замороженных интерфейсов Фазы 0.
- **Коммит/пуш — только по явной просьбе пользователя.**
