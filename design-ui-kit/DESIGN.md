# MOROK — дизайн-спецификация для внедрения

Пакет для разработчика: два HTML-файла (самодостаточные, открываются офлайн) и этот документ.

- `MOROK Demo Flow.html` — кликабельный мок всех 6 экранов. Это **референс внешнего вида и поведения**, не продакшен-код. Задача — воссоздать его в существующем стеке приложения (текущий UI на FastAPI/Jinja или любой фронтенд-фреймворк), используя описанные ниже токены и компоненты.
- `design_kit/` — дизайн-кит для внедрения: `css/tokens.css`, `css/base.css`, `css/components.css`, `js/components.js`, `tokens.json`, демо каждого компонента в `components/`, спецификации в `docs/`, обзор — `design_kit/index.html`.

Фиделити: **hi-fi**. Цвета, размеры, отступы и типографика финальные — повторять точно.

---

## 1. Принципы

1. Витрина, не пульт. Минимум настроек; каждый экран показывает один этап и одно главное действие.
2. Одно брендовое действие на экран: красная кнопка `#ef3124` — только главный CTA шага. Всё остальное — тёмная `#121213` или secondary.
3. Данные — моно. Идентификаторы, аргументы вызовов, вердикты, метрики, логи, метаданные — `JetBrains Mono`. Текст интерфейса — `Golos Text`.
4. Красный статуса ≠ брендовый красный. Риск/PROVEN — `#ec2d20`, бренд — `#ef3124`.
5. Контент заполняет экран: сетки и карточки растягиваются на высоту, навигация шага прижата к низу. Пустых полей справа/снизу быть не должно.

### Радиусы

`99px` кнопки, бейджи, чипы, шаги · `20px` карточки · `16px` баннеры, drop-зоны, элементы списка сценариев, плашка «Цель аудита» · `12px` строки списков, поля ввода, плашки параметров · `10px` узлы схемы, иконки-квадраты.

### Отступы

`4 · 8 · 12 · 16 · 24 · 28 · 40`.
Padding карточки 24. Gap между карточками 24. Между строками списка 8. Между элементами в строке 12. Между блоками внутри карточки 14–16. Контент: `28px 40px 40px`.

### Тени

Не используются. Иерархия — цветом поверхности и рамками.

### Анимации

- Прогресс-бар: `width` transition `.5s ease`.
- RUNNING-бейдж и курсор лога: `mk-pulse` (opacity 1 → .35 → 1) 1–1.2s infinite.
- Спиннер статуса: `mk-spin` .9s linear infinite, 14px, border 2px `rgba(15,25,55,.15)`, top `#121213`.
- Hover кнопок — мгновенная смена фона, без transition.

## 3. Каркас экрана

```
┌───────────────────────────────────────────────────────────────┐
│ Шапка 60px · #121213                                          │
│ [☰] [глаз] MOROK      ( 1 Контекст | 2 … | 6 Для бизнеса )   ● стенд │
├──────────┬────────────────────────────────────────────────────┤
│ Сайдбар  │ Контент · #f2f3f5 · padding 28 40 40 · gap 24      │
│ 288px    │ ┌ meta 12 mono                                     │
│ #fff     │ │ H1 28                                            │
│          │ └ лид 15                                            │
│ Цель     │ ┌──────────────────┐ ┌──────────────┐               │
│ Подкл.   │ │ карточка 20/24   │ │ карточка     │  ← flex:1     │
│ Модели   │ └──────────────────┘ └──────────────┘               │
│ История  │ [← назад secondary]           [главное действие →] │
└──────────┴────────────────────────────────────────────────────┘
```

- Высота приложения `100vh`, прокручивается только контент (и сайдбар при переполнении).
- Шапка: кнопка сворачивания сайдбара 36×36 radius 10 (`fill-on-dark`), логотип-глаз 44×30 + «MOROK» 17/700 letter-spacing .18em, по центру группа шагов, справа чип стенда (моно 12, точка статуса).
- Шаги — pill-группа: фон `fill-on-dark`, padding 3, gap 2. Кнопка шага `7px 12px`, 13/500; кружок номера 18px моно 11. Состояния: активный — фон `#fff`, текст `#121213`, кружок `rgba(15,25,55,.1)`; пройденный — «✓» на `positive-muted`/`positive`; будущий — текст `text-on-dark-secondary`, кружок `rgba(214,214,229,.12)`. Все шаги кликабельны всегда (демо должно позволять прыгать назад/вперёд).
- Сайдбар универсален и не зависит от сценария: «Цель аудита» (плашка 16px `bg-page`: имя, моно-id, статус) → «Подключение» (4 строки label/value, до синхронизации — «не проверено») → «Модели» (генератор / целевой агент / автор отчёта, моно 12) → «История прогонов» (карточки-кнопки, ASR красным). Заголовки секций — 11/700 caps `text-tertiary`. Gap между секциями 28.
- Минимальная целевая ширина 1280 (демо на проекторе). Ниже 1100 — сетки схлопываются в одну колонку, шаги в шапке переносятся на вторую строку.

## 4. Компоненты

### Кнопки
- Primary brand: `#ef3124`, hover `#e32a17`, текст `#fff` 14/600, padding `13px 24px`, radius 99. Один на экран.
- Primary dark: `#121213`, hover `#29292c`, те же размеры. Для «дальше →».
- Secondary: `fill-secondary`, hover `fill-secondary-hover`, текст `text-primary` 14/500, padding `13px 20px`. Для «← назад», «Скачать всё».
- Small: `8px 14px`, 13/600 (кнопка «Скачать» в баннере).
- Без рамок, без теней, `font-family: inherit`.

### Карточка
`#fff`, radius 20, padding 24, `display:flex; flex-direction:column; gap:14–16`. Заголовок 16/600, справа опционально мета (моно 11–12 `text-tertiary`/`text-secondary`) — `justify-content:space-between; align-items:baseline`.

### Строка списка (файл, компонент, проверка)
`bg-page`, radius 12, padding `11px 14px`, `gap 12`, `align-items:flex-start`. Слева тип файла моно 11/600 `text-secondary` шириной 40; далее колонка: имя 13/500 (переносится, `overflow-wrap:anywhere`), мета 12 `text-secondary`. Не обрезать имена многоточием.

### Элемент списка сценариев
Кнопка `#fff`, radius 16, padding `16px 18px`, рамка 1.5px `border`; выбранный — рамка `#121213`. Содержимое: имя 14/600 + счётчик моно 11 справа; описание 12 `text-secondary`; тег поверхности (`2px 8px`, 11/600: память → attention, MCP → info, остальное `bg-page`/`rgba(4,4,19,.7)`).

### Бейдж вердикта / статуса
Моно 11/600, padding `3px 9px`, radius 99.
PROVEN `negative-muted`/`negative` · NOT PROVEN `positive-muted`/`positive` · RUNNING `info-muted`/`info` + pulse · PENDING `fill-secondary`/`text-secondary` · PASS = NOT PROVEN · FAIL = PROVEN.
Критичность — Golos 11/700 caps .04em: Критично negative · Высокий attention · Отражено positive.

### Индикатор подключения
Точка 7px radius 99 + текст 12–13/500. Подключён: `positive-dot`/`positive`. Не проверено: `text-tertiary`. В сайдбаре — точка 6px, значение моно 12.

### Поля ввода
Рамка 1px `border`, radius 12, padding `11px 14px` (textarea `12px 14px`), фон `#fff`. Технические значения — моно 13; свободный текст — Golos 14/1.55. Label над полем 12 `text-secondary`, gap 6. Focus: `outline 2px rgba(15,25,55,.25)`. Drop-зона: 1.5px dashed `border-dashed`, radius 16, фон `bg-page`, padding 18–22.

### Чипы-переключатели (аудитория)
`8px 14px`, radius 99, 13/500, рамка 1.5px. Выбран: фон и рамка `#121213`, текст `#fff`. Не выбран: `#fff`, рамка `rgba(15,25,55,.15)`.

### Вкладки внутри контента
Группа `fill-secondary`, radius 99, padding 3, gap 2. Кнопка `7px 16px` 13/500; активная — `#fff`/`text-primary`, остальные `text-secondary`.

### Таблица (компоненты, находки)
CSS grid, gap колонок 14–16. Заголовки 11/700 caps .08em `text-tertiary`, `padding 12px 0 10px`, нижняя граница `border`. Строки `padding 13px 0`, граница `border-soft`, 13px. Идентификаторы и evidence — моно. Первая ячейка находки несёт полосу критичности 3px слева (`negative-bar` / `attention-border` / transparent), вынесенную за край сеткой (`margin-left:-13px; padding-left:10px`). Без зебры. Таблица находок — минимальная ширина 900, горизонтальная прокрутка внутри карточки.

### Баннер результата
Radius 16, padding `16px 20px`, gap 14. Успех: `positive-muted`, круг 32px `positive-dot` с «✓», заголовок 15/600 `positive`, подпись 13 `rgba(3,3,6,.7)`.
Итог отчёта: карточка `#fff` radius 20, overflow hidden; строка «Итог» (label 11 caps, `COMPROMISED` моно 28/700 `negative`, бейдж «Критично», справа имя сценария), ниже 4 метрики в grid `repeat(4,1fr)` (label 12 secondary, значение моно 22/600, разделители `border`), внизу шкала 4px `bg-page` с заливкой `negative-bar` на ширину ASR.

### Схема архитектуры
Плашка `bg-page` radius 16 padding 18; строки узлов flex-wrap gap 8. Узел: `9px 12px`, radius 10, моно 12/500, рамка 1px. Обычный — `#fff`/`border`; поверхность атаки — `attention-muted`/`attention-border`/`attention`; MOROK-компонент — `#121213`/`#fff`. Точка входа — синяя точка 7px внутри узла. Стрелка «→» `text-tertiary`. Легенда 12 под схемой.

### След (trail) находки
Горизонтальная цепочка из 6 узлов `flex:1; min-width:120`, соединитель 18×1.5px `rgba(15,25,55,.2)`. Узел: radius 12, padding `12px 14px`, stage 11/700 caps, detail моно 11/1.45. Обычный — `bg-page`; точка компрометации — `negative-muted`, рамка 1.5px `negative-bar`, stage `negative`.

### Панель лога
Единственная тёмная поверхность в контенте: `#121213`, radius 20, padding 24, min-height 380, текст моно 12/1.5. Строка: время `text-on-dark-tertiary` + событие; событие `text-on-dark` (probe), `text-on-dark-secondary` (вызов агента), `log-negative` (PROVEN), `log-positive` (NOT PROVEN). Пульсирующий курсор 8×14 при работе; в ожидании — строка «ожидание запуска…». Показывать последние ~9 строк.

### Прогресс прогона
Карточка: строка статуса (спиннер + 15/600) и счётчик моно 13 `nowrap` справа; полоса 6px radius 99 `bg-page` с заливкой `#121213`; ниже 4 счётчика 13 (Доказано — `negative`).

## 5. Экраны

Все экраны имеют шапку-заголовок: мета моно 12 («Шаг N из 6 · …») → H1 → лид. Кнопки навигации шага — последний ряд контента, `margin-top:auto`.

2. **Синхронизация со стендом** — баннер успеха; grid 3/2: «Загруженная архитектура» (схема) | «Подключение» (5 проверок PASS); на всю ширину таблица «Найденные компоненты и способ интеграции». Кнопки: «← Изменить контекст» / «К сценариям атак →» (dark).

## 6. Состояние и поведение

- `step` 1–6; переход по шагам в шапке и кнопкам. Переход на 5/6 при незавершённом прогоне трактует прогон как завершённый (демо-режим).
- `sidebarOpen` — кнопка ☰ в шапке.
- `connected = step ≥ 2` — меняет чип стенда и блок «Подключение» в сайдбаре.
- `selectedScenario` — влияет на шаги 3–6 (список атак, вердикты, ASR, отчёт).
- `run: {status: idle|running|done, done, log[]}` — «Запустить сценарий» стартует таймер (~650 мс на фазу: probe → вызов → вердикт), статусы строк меняются PENDING → RUNNING → PROVEN/NOT PROVEN, по завершении появляется «Открыть отчёт →».
- `reportTab`, `audiences`, `bizText`, `bizDone`.
- Элемент истории в сайдбаре открывает завершённый отчёт по своему сценарию.
